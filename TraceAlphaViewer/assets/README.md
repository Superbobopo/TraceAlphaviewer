# Logo TraceAlphaViewer

Logo cree avec l'outil integre `imagegen`, sans API ni cle externe.
Le A evoque Alpha, les boites et le convoyeur representent la machine,
et le signal avec son point ambre evoque les traces et le diagnostic.

- `trace-alpha.png` : image source RGBA avec transparence.
- `trace-alpha.ico` : conversion du PNG en icone Windows, avec les tailles
  16, 24, 32, 48, 64, 128 et 256 pixels. Aucune retouche du dessin.

Consigne exacte envoyee a l'outil :

> Use case: logo-brand. Asset type: square Windows executable app icon for TraceAlphaViewer, a local industrial Alpha conveyor trace viewer and diagnostic tool. Create one bold, polished professional logo symbol: an angular capital A integrated with a conveyor carrying two small boxes, with a subtle trace pulse crossing the A. Navy rounded-square tile, luminous teal and sky blue symbol, one small amber diagnostic point. Simple strong silhouette legible at 32 pixels, balanced centered composition, generous margins, flat crisp vector-like raster illustration. No words, no tiny details, no watermark, no mockup, only the final single app icon. Background outside the rounded-square tile truly transparent.
